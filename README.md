# SwipeClean

Чистка галереи iPhone свайпами: влево — в корзину, вправо — оставить, вверх — в избранное, вниз — решу позже.

## Что умеет

- **Разбор свайпами** по месяцам, альбомам, скриншотам, видео и другим подборкам. Отмена последнего решения, корзина с подтверждением перед удалением.
- **Умная чистка**: точные дубли, похожие кадры, скриншоты, размытые фото, тяжёлые видео, почта iCloud и Gmail. Период — месяц, квартал, год или всё время.
- **Память iPhone**: сколько занято и чем. Каждый раздел фото и видео открывается подробно: группы по размеру (например, видео от 1 ГБ), размер каждого файла на превью, порядок по размеру или по дате. Группу можно выбрать целиком и отправить в корзину.
- **Инструменты**: сжатие фото и видео, Live Photos в обычные фото (видео убирается, снимок остаётся без пережатия), секретная папка под PIN-кодом и Face ID, дубли контактов с резервной копией vCard и отменой, старые события календаря, чистка почты iCloud и Gmail (можно оба ящика сразу; по категориям и по отправителям: всё от ненужного отправителя — в корзину разом).
- **Не трогать**: список фото и видео, которые приложение никогда не предложит удалить. Добавить можно из медиатеки или кнопкой в полноэкранном просмотре; избранное по умолчанию тоже защищено. Защищённых нет в разборе, умной чистке, разделах памяти и сжатии, а из корзины они возвращаются.
- **Статистика**: сколько разобрано и освобождено, серии дней.
- **Серия и напоминание**: сколько дней подряд вы чистили галерею — на главной. Ежедневное уведомление в выбранное время: «В этот день: 23 фото» или просьба не прерывать серию. В дни, когда уже чистили, не приходит.

## Приватность

- Всё работает на iPhone. Нет серверов, аналитики, рекламы и сторонних библиотек.
- Единственные сетевые соединения — к `imap.mail.me.com` и `imap.gmail.com`, и только если подключить почту iCloud или Gmail. Вход по паролю приложения (Apple: account.apple.com, Google: myaccount.google.com/apppasswords, нужна двухэтапная аутентификация). Приложение читает лишь заголовки писем (отправитель, тема, размер): тела, ссылки и вложения не загружаются. Пароли приложений хранятся в связке ключей этого iPhone.
- Удалённые фото попадают в «Недавно удалённые» и ещё 30 дней их можно вернуть.
- Секретная папка не попадает в резервную копию iCloud. После пяти неверных PIN-кодов подряд ввод блокируется на 30 секунд, и каждая следующая ошибка удваивает паузу.

## Установка на iPhone

Приложения нет в App Store, поэтому его подписывают своим Apple ID. Это бесплатно, но у Apple есть ограничения для бесплатных аккаунтов:

- подпись действует **7 дней**, потом приложение перестаёт открываться, пока его не переустановить. Данные при переустановке поверх сохраняются;
- на одном iPhone может быть не больше трёх приложений, установленных так, и не больше 10 новых приложений в неделю.

Понадобятся iPhone с iOS 17 или новее, компьютер с Windows или macOS, кабель и Apple ID. Если не хочется вводить основной Apple ID в стороннюю программу, заведите отдельный.

### Способ 1. Sideloadly (Windows и Mac)

1. Скачайте `SwipeClean.ipa` со страницы [Releases](../../releases/latest).
2. Установите [Sideloadly](https://sideloadly.io/). На Windows ещё нужны iTunes и iCloud с сайта Apple (не из Microsoft Store).
3. Подключите iPhone кабелем, разблокируйте его и нажмите «Доверять этому компьютеру».
4. Перетащите `SwipeClean.ipa` в окно Sideloadly, впишите Apple ID и нажмите **Start**. Введите пароль Apple ID, а если попросит — код подтверждения.
5. На iPhone включите режим разработчика: **Настройки → Конфиденциальность и безопасность → Режим разработчика**. iPhone перезагрузится и спросит подтверждение ([как это описывает Apple](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device)).
6. Разрешите запуск: **Настройки → Основные → VPN и управление устройством** → ваш Apple ID → **Доверять**.
7. Раз в 7 дней повторяйте шаг 4. Приложение установится поверх, данные останутся.

Если Sideloadly пишет, что идентификатор приложения недоступен, откройте **Advanced options** и впишите свой Bundle ID, например `com.yourname.swipeclean`.

### Способ 2. AltStore (продлевает подпись сам)

[AltStore Classic](https://altstore.io/) продлевает подпись автоматически, когда iPhone и компьютер с AltServer в одной сети Wi-Fi.

1. Установите AltServer на компьютер и через него AltStore на iPhone по [инструкции AltStore](https://faq.altstore.io/).
2. Сохраните `SwipeClean.ipa` в «Файлы» на iPhone.
3. В AltStore откройте **My Apps → +** и выберите `SwipeClean.ipa`.

AltStore сам занимает одно из трёх мест для таких приложений.

### Способ 3. Xcode на Mac (из исходников)

1. Установите Xcode из App Store и [XcodeGen](https://github.com/yonaskolb/XcodeGen): `brew install xcodegen`.
2. Скачайте код (**Code → Download ZIP**) или `git clone`.
3. Задайте свой идентификатор приложения. Он должен быть уникальным:

   ```bash
   echo 'APP_BUNDLE_ID = com.yourname.swipeclean' > Config/Local.xcconfig
   ```

4. Соберите проект и откройте его:

   ```bash
   xcodegen generate
   open SwipeClean.xcodeproj
   ```

5. В Xcode: **Settings → Accounts** → добавьте Apple ID. Затем цель SwipeClean → **Signing & Capabilities** → **Team** → ваша Personal Team.
6. Подключите iPhone, выберите его вверху окна и нажмите ▶. Режим разработчика и доверие — как в шагах 5–6 первого способа.
7. Раз в 7 дней нажимайте ▶ снова.

Чтобы команда не сбрасывалась после `xcodegen generate`, допишите её в `Config/Local.xcconfig`: `DEVELOPMENT_TEAM = ABCDE12345` (ID видно в Xcode в настройках подписи).

## Для разработчиков

Swift 6, SwiftUI, PhotoKit, iOS 17+, без зависимостей. Проект описан в `project.yml` для XcodeGen; проверено на Xcode 27.1.

- `SwipeClean/App` — точка входа и корневая навигация
- `SwipeClean/Services` — медиатека, умная чистка, почта, хранилище решений
- `SwipeClean/Features` — экраны по разделам
- `Config/Signing.xcconfig` — команда разработчика и bundle id по умолчанию; свои значения — в `Config/Local.xcconfig`, его нет в git

### Тесты

```bash
xcodegen generate
xcodebuild test -project SwipeClean.xcodeproj -scheme SwipeClean -destination 'platform=iOS Simulator,name=iPhone 17'
```

Модульные тесты покрывают дубли и похожие кадры, метрики изображений, хранилище решений, статистику, разбор ответов IMAP, сжатие и секретную папку. UI-тесты (`SwipeCleanUITests`) проходят каждый сценарий в настоящем приложении на симуляторе. Перед прогоном наполните медиатеку симулятора:

```bash
scripts/seed-simulator.sh <UDID симулятора>
```

Каждый прогон по-настоящему удаляет из медиатеки симулятора одно фото.

### Сборка .ipa

```bash
scripts/build-ipa.sh
```

Собирает неподписанный `build/ipa/SwipeClean.ipa`. Sideloadly и AltStore подписывают его Apple ID того, кто устанавливает.
